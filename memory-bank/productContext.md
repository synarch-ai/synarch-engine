# Product Context: Synarch Engine

## Problem Statement
AI agent frameworks (CrewAI, AutoGen, LangGraph) are libraries, not products. Users must build everything: orchestration, UI, memory, security, monitoring. Bhanu Teja proved autonomous agent teams work at SiteGPT — but his system is closed-source, insecure, ad-hoc, and marketing-only.

## Target Users
1. **Solo developers** who want an AI team working 24/7 on their projects
2. **Startups** that need to scale operations without hiring (like Bhanu)
3. **Open-source community** wanting a self-hostable alternative to SaaS agent platforms

## Value Proposition
| What Exists | What Synarch Adds |
|---|---|
| Single agents (ChatGPT, Claude) | Autonomous agent TEAMS with hierarchy |
| Agent frameworks (CrewAI, AutoGen) | Production-grade PRODUCT with dashboard |
| Bhanu's SiteGPT system (closed) | Open-source, secure, self-evolving |
| Polling-based communication | Event-driven nervous system (NATS) |
| No observability | Real-time Mission Control dashboard |

## User Experience Goals
- **One-liner start:** `docker compose up` + start script
- **Visual observability:** See agents think in real-time
- **God mode:** Configurable autonomy (guided → supervised → free rein)
- **Any domain:** Marketing, dev, research, personal productivity — define your own agent team

## Competitive Differentiation
Nobody has built an open-source "operating system for autonomous agent teams" with hierarchy, event-driven communication, soul-based personas, and a Mission Control dashboard. We are first.
